
# Veda Technology Business & Service Analytics

**Day 37 – Data Science Internship Project**

## Project Overview
This project analyzes synthetic business data representing Veda Technology's website traffic, internship applications, training programs, IT and digital services, customer inquiries, and marketing channels.

## Objectives
- Clean and preprocess business data.
- Analyze website visitors and internship applications.
- Evaluate training and service performance.
- Identify customer inquiry patterns and marketing trends.
- Calculate business KPIs.
- Perform basic predictive analysis.
- Present insights and recommendations.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Key Business Insights
- Highest website traffic: Social Media
- Highest internship applications: West
- Highest training revenue: Python Training
- Highest inquiry demand: Internship
- Largest customer segment: High Revenue
- Total visitors: 153,303
- Total revenue: 15,820,595
- Predictive model MAE: 21,869.47

## Data Privacy
This project uses synthetic sample data and does not contain private or confidential company information.

## Conclusion
The project demonstrates how Python and Pandas can be used to analyze business performance, calculate KPIs, identify patterns, and support data-driven decisions.
